# Watch settings

Filled by `references/step-0-interview.md`. Page fields filled by `references/step-2-build-page.md`.

| Setting | Value | Notes |
|---|---|---|
| watchName | | Name shown on the page, e.g. "Cyber Watch", "Veille Marketing" |
| field | | One sentence: what this watch covers |
| purpose | | Why the user follows it: job, clients, decisions it feeds |
| sourceLanguages | | `fr` (French only), `en` (English only) or `fr+en` (both) |
| displayLanguage | | `fr` or `en`: page, tag labels, Claude's lines, translated titles |
| cadence | weekly | `weekly` (default) or `daily` |
| runDay | | e.g. Friday (weekly only) |
| runTime | | e.g. 07:00 |
| timeZone | | e.g. Europe/Paris |
| packs | | Starting packs used, e.g. `ai`, `cybersecurity` |
| pageUrl | | Filled by step 2 |
| pageId | | Filled by step 2 |
| localFolder | | Optional: folder path on the user's computer, for the mirror add-on |
