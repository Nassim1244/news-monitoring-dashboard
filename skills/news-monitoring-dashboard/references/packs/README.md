# Starting packs

A pack is a starting point: a tag tree, hints for the bucket rules, and candidate sources. Step 0 lets the user pick 0 to 3 packs; step 1 merges and refines them. Nothing in a pack is final.

| Pack | File | For |
|---|---|---|
| AI | `ai.md` | AI models, agents, tools, adoption in companies |
| Cybersecurity | `cybersecurity.md` | Threats, vulnerabilities, regulation, defense practice |
| Marketing | `marketing.md` | Digital marketing, search, social, CRM, martech |
| Industry | `industry.md` | Manufacturing, industry 4.0, supply chain, energy in plants |

Candidate sources are **not tested**. Step 0 tests each one with WebFetch and finds the right feed URL. Only the AI pack lists feeds tested in November 2026.

To make a new pack, copy one file and keep the same sections.
